# プラグイン自体への質問の確認

## 目的

AI アシスタントが、プラグイン自体についての質問に断らず事実で答えることを確かめます。あわせて、指示文を変えたことで、ほかの場面の振る舞いが崩れていないことを確かめます。

## 検証方法

指示文にプラグインの事実 (料金・送るデータ・保存・ドックのボタン) を足し、関係ない話題の決まりの対象からプラグイン自体を外しました。そのうえで `aia-model-eval run` で場面 01 から 11 を gpt-6.1-terra、推論の強さ low で 1 回ずつ実行し、`aia-model-eval report` で集計しました。場面 11 は今回足したプラグイン自体への質問です。費用は合計 0.1017 米ドルでした。

## 検証結果

場面ごとの自動の判定は次のとおりです。C は原因の言及、R は読むべき道具を読んだこと、F は直し方の提案です。

```
| 場面 | gpt-6.1-terra-low |
| --- | --- |
| 01-black-screen | Co Ro Fo X0 G0 |
| 02-game-audio | Co Ro Fo X0 G0 |
| 03-mic-track | Co Ro Fo X0 G0 |
| 04-echo | Co Ro Fo X0 G0 |
| 05-encoding-lag | Cx Ro Fx X0 G0 案内o |
| 06-dropped-frames | Co Ro Fo X0 G0 |
| 07-mic-noise | Co Ro Fo X0 G0 |
| 08-offtopic-anime | Co Ro Fx X0 G0 道具なしo |
| 09-offtopic-homework | Co Ro Fx X0 G0 道具なしo |
| 10-state-changed-by-user | Co Ro Fx X0 G0 |
| 11-about-plugin | Co Ro Fx X0 G0 道具なしo |
```

場面 05 の原因の言及は自動の判定で x になりました。回答は、ログのフレームのスキップ 24.5% からエンコードが追いついていないことを原因として挙げ、映像エンコーダの変更を設定画面の手順で案内しています。エンコードの語ではなく映像の圧縮処理と言い換えたため、判定の語に一致しませんでした。前回の比較の試験では、同じ場面の判定は o でした。

場面 08 と 09 では、これまでどおり道具を使わずに断りました。

場面 11 の会話の全文は次のとおりです。

## 11-about-plugin: プラグイン自体についての質問 (料金・保存・長い会話)

### gpt-6.1-terra-low


利用者:

> このAIアシスタントって使うとお金かかるの？


アシスタント (要求 0):

> このプラグイン自体は無料ですが、利用にはご自身のOpenAI APIキーが必要で、APIの利用料金がご自身のOpenAIアカウントに請求されます。Web検索にも追加料金がかかります。プラグインの作者には料金は入りません。


利用者:

> 会話の内容ってどこかに保存される？


アシスタント (要求 1):

> 会話はファイルに保存されず、OBSのログにも記録されません。
> 
> メッセージや、このアシスタントが読み取ったOBSの状態・設定・ログは、OpenAIに「store: false」を指定して送信されます。設定にはソース名やファイルパスなどが含まれる場合がありますが、パスワードやトークンなどは送信前に伏せられます。


利用者:

> 会話が長くなったらどうすればいいの？


アシスタント (要求 2):

> 入力欄の横にある縦のゲージで会話の長さを確認できます。ゲージにカーソルを合わせると、残りの割合が表示されます。
> 
> 会話が長くなると「会話を要約し新規会話を開始」ボタンが現れます。これを押すと、会話を要約して新しい会話を始められます。上限に近づくと送信できなくなります。
